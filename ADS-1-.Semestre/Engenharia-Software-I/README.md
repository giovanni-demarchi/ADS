# 🛠️ Engenharia de Software I

## 📖 Sobre a disciplina

Este diretório reúne os materiais e atividades relacionados à disciplina de **Engenharia de Software I**, do curso de Análise e Desenvolvimento de Sistemas da FATEC Lins.

A disciplina apresenta conceitos, processos e técnicas utilizados na análise, no planejamento, na especificação e na documentação de sistemas de software.

## 🎯 Objetivo

Compreender as etapas fundamentais do processo de desenvolvimento de software, desde a identificação das necessidades dos usuários até a definição e documentação de uma solução.

## 📚 Principais conteúdos

### 1. Fundamentos de Engenharia de Software
- Conceitos e objetivos
- Ciclo de vida de software
- Processos de desenvolvimento
- Qualidade e manutenção de software

### 2. Engenharia de Requisitos
- Levantamento de necessidades
- Identificação de usuários e partes interessadas
- Requisitos funcionais
- Requisitos não funcionais
- Restrições e regras de negócio

### 3. Análise e documentação
- Documento de visão e escopo
- Especificação de requisitos
- Organização do backlog inicial
- Análise de viabilidade
- Modelagem de processos e funcionalidades

### 4. Planejamento de sistemas
- Definição do problema
- Identificação dos objetivos
- Delimitação do escopo
- Priorização de funcionalidades
- Organização das entregas

## 🚀 Aplicação prática

Os conhecimentos da disciplina são aplicados ao planejamento do **Sistema Web para Gestão de Academia**, desenvolvido como parte do Projeto Integrador ADS I.

O projeto envolve:
- Identificação de problemas e necessidades do negócio
- Análise de soluções existentes
- Levantamento dos requisitos do sistema
- Definição de funcionalidades essenciais
- Elaboração de documentação técnica
